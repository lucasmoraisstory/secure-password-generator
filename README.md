# Gerador de Senhas Seguras 🔒

Utilitário em Python voltado para Segurança da Informação que gera chaves de autenticação e senhas criptográficas complexas de forma pseudoaleatória, atendendo aos padrões internacionais de conformidade e segurança digital.

###  Tecnologias Utilizadas
- Python 3
- Módulo nativo `random` (Para seleção aleatória de dados)
- Módulo nativo `string` (Para manipulação e agrupamento de constantes de caracteres ASCII)

### Funcionalidades
- Criação automatizada de strings complexas contendo letras maiúsculas, minúsculas, numerais e caracteres especiais.
- Alerta inteligente de segurança para senhas com comprimento abaixo do limite recomendado.
